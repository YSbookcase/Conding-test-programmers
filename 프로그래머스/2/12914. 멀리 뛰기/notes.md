# 멀리 뛰기 (12914)

## 상태
- 제출 완료. 정확성 100, 합계 100. 메모리 46.3 MB, 시간 0.10 ms
- 제출 파일: `프로그래머스/2/12914. 멀리 뛰기/멀리 뛰기.cs`
- 고득점 Kit 연습문제

## 내가 한 질문
- "1234567로 나눈 나머지를 리턴"이 무슨 의미인가?
- 숫자가 늘어도 직전 경우의 수에서 추가되는 경우만 따지면 되나?
- `n` 위치의 피보나치 값인가?
- `long`으로 계산하면 되나? 재귀로 구하면 부담되지 않았나?
- `n`이 2일 때도 커버되나?
- 반복문은 시작 전에 조건을 확인하나?
- 피보나치인 것을 모르면 풀기 어렵지 않나?

## 막혔던 지점
- 1234567로 나눈 나머지는 `%`다. 예제 5와 3은 제수보다 작아서 경우의 수 그대로다. `n`이 2000이면 경우의 수는 `long`을 넘는다. 더할 때마다 나머지를 저장한다.
- 수열 전체를 더한 합이 아니다. `n`번째 항 하나이고, 그 항은 한 칸 전과 두 칸 전을 더한 값이다.
- 이 문제의 `n`칸은 `1, 2, 3, 5, 8, …`의 `n`번째다. `1, 1, 2, 3, 5`로 시작하는 피보나치라면 `n + 1`번째다.
- 이름보다 표가 먼저다. 1칸 1가지, 2칸 2가지, 3칸 3가지, 4칸 5가지. 마지막 점프가 1칸이면 `n - 1`, 2칸이면 `n - 2`라서 둘을 더하면 된다.
- 나머지 없이 피보나치 전체를 `long`에 넣으면 90을 넘어 넘친다. 재귀는 같은 항을 반복해서 다시 구하고, `n`이 2000이면 호출이 감당되지 않는다. 앞의 두 값만 두고 반복한다.
- `for`는 본문 전에 조건을 본다. `distance`가 3부터이고 `n`이 2이면 `3 <= 2`가 거짓이라 본문이 한 번도 실행되지 않는다. 미리 넣어 둔 `current`인 2가 반환된다. 2칸은 `(1,1)`과 `(2)`의 2가지다.

## 문제 한 줄
1칸 또는 2칸으로 `n`칸 끝에 가는 경우의 수를 `1234567`로 나눈 나머지. `n`은 1 이상 2000 이하.

## 핵심 패턴
```text
n이 1이면 1
previous = 1, current = 2
3부터 n까지 next = (previous + current) % 1234567
previous = current, current = next
current 반환
```

```csharp
if (n == 1)
{
    return 1;
}

long previous = 1;
long current = 2;
int divisor = 1234567;

for (int distance = 3; distance <= n; distance++)
{
    long next = (previous + current) % divisor;
    previous = current;
    current = next;
}

return current;
```

- `4` → `5`
- `3` → `3`
- `1` → `1`
- `2` → `2`. 반복은 돌지 않는다.

## 다음에 볼 것
- 4칸을 표로 적는다. 마지막이 1칸이면 3칸의 3가지, 마지막이 2칸이면 2칸의 2가지. 합이 5다.
- 나머지는 마지막에 한 번이 아니라 덧셈마다 취한다.
- `distance`는 지금 채우는 칸 수다. 1칸, 2칸 점프 길이와는 다른 변수다.
