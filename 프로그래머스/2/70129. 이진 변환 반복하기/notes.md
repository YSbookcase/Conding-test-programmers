# 이진 변환 반복하기 (70129)

## 상태
- 제출 완료. 정확성 100, 합계 100. 메모리 47 MB, 시간 3.74 ms
- 제출 파일: `프로그래머스/2/70129. 이진 변환 반복하기/이진 변환 반복하기.cs`
- 월간 코드 챌린지 시즌1. LocalTest에서 `while (s != "1")`로 작성해 제출

## 내가 한 질문
- 남은 1로 구성된 값의 길이를 2진수로 나타내는 건가
- `s`는 선언이 없는데 `string`으로 선언하면 되나
- 추가로 볼 점이 있나

## 막혔던 지점
- 0을 지운 뒤 남은 문자열은 1만 있다. 다음 `s`는 그 1들을 이진수 값으로 읽은 결과가 아니라, 그 길이의 2진수 문자열이다. `"0111010"`은 `"1111"`이 되고, 길이 4의 2진수가 `"100"`이다.
- `s`는 `solution(string s)`의 매개변수다. 안에서 `string s`를 다시 선언하지 않는다. `s = Convert.ToString(oneCount, 2)`가 그 매개변수를 다음 문자열로 바꾼다.
- `"1"`이면 반복에 들어가지 않는다. 한 번 더 바꾸면 1의 개수가 다시 1이라 `"1"`이 계속 나온다. 시작이 `"1"`이면 `[0, 0]`이다.
- 0을 하나도 지우지 않은 회차도 변환 횟수에 들어간다. `"11"`은 0을 0개 지우지만 `"10"`으로 바뀌므로 1회다. `"01110"`의 횟수가 2가 되면 0을 지운 회차만 센 것이다.

## 문제 한 줄
`s`가 `"1"`이 될 때까지 0을 지우고, 남은 길이를 2진수 문자열로 바꾼다. 반환은 `[변환 횟수, 지운 0의 합]`이다. `s`의 길이는 15만 이하이고 1이 하나 이상 있다.

## 핵심 패턴
```text
s가 "1"이 아니면
  0의 개수와 1의 개수를 센다
  지운 0에 더한다
  s = 1의 개수를 2진수로 쓴 문자열
  변환 횟수 1 증가
[변환 횟수, 지운 0의 합] 반환
```

```csharp
while (s != "1")
{
    int zeroCount = 0;
    int oneCount = 0;

    foreach (char bit in s)
    {
        if (bit == '0')
            zeroCount++;
        else
            oneCount++;
    }

    removedZeroCount += zeroCount;
    s = Convert.ToString(oneCount, 2);
    transformCount++;
}
```

`oneCount`는 0을 지운 뒤의 길이다. 첫 변환 뒤의 문자열은 그 길이를 2진수로 쓴 자리수라 아주 짧아진다.

| s | 결과 | 확인 |
|---|---|---|
| `"1"` | `[0, 0]` | 반복 없음 |
| `"10"` | `[1, 1]` | 0 하나, 길이 1 |
| `"01110"` | `[3, 3]` | 둘째 회차는 0을 0개 지움 |
| `"1111111"` | `[4, 1]` | 앞의 세 회차는 0을 지우지 않음 |
| `"110010101001"` | `[3, 8]` | 6개, 1개, 1개 |

## 다음에 볼 것
- 반환 순서는 변환 횟수, 그다음 지운 0의 합이다.
- 제출본의 `bit`는 `s`의 한 글자이고, `oneCount`는 남은 1의 개수다. `transformCount`는 0을 지웠는지와 상관없이 반복이 한 번 돌 때마다 증가한다.
