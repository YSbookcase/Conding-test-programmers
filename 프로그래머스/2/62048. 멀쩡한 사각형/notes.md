## 내가 한 질문
- 최대공약수로 나눈 위치에서 패턴이 반복되는 것이 힌트가 될 것 같다
- 한 블록에서 대각선이 지나가는 칸 수가 그 개수인 이유는 모르겠다. 블록 개수만큼 곱하는 것은 알겠다
- 어려워 보였는데 아이디어가 있으면 구성은 간단하다. 더 볼 점이 있나
- 로컬 테스트 결과가 왜 달라지나

## 막혔던 지점
- 한 블록에서 잘리는 칸은 가로와 세로를 곱한 값이 아니다. 서로소인 `w × h`는 시작 칸 1개, 세로 격자선 `w - 1`번, 가로 격자선 `h - 1`번이다. `1 + (w - 1) + (h - 1) = w + h - 1`.
- 예제의 한 블록은 `2 × 3`이다. 대각선은 6칸 중 `(0,0) → (0,1) → (1,1) → (1,2)` 네 칸만 지난다. `x = 1`일 때 `y = 1.5`라 안쪽 격자점을 밟지 않아서, 옆 이동과 위 이동을 각각 더한다.
- `gcd(8, 12) = 4`이므로 이 블록이 대각선 방향으로 4번 이어진다. `4 × 4 = 16`칸이 잘리고, `96 - 16 = 80`이다. 합치면 `W + H - gcd(W, H)`.
- 오른쪽 끝 `x = w`와 위쪽 끝 `y = h`는 종이 테두리다. 도착해도 새 칸이 생기지 않아 넘김 횟수는 `w`, `h`가 아니라 `w - 1`, `h - 1`이다.
- LocalTest는 `brokenCount`를 만든 뒤 `width + height - brokenCount`를 반환했다. `brokenCount`가 이미 `width + height - gcd`라 결과가 최대공약수만 남는다. 8, 12이면 4다. 전체 칸 `width * height`에서 빼야 80이다.
- `W`, `H`가 1억이면 곱은 `int`를 넘는다. `width`, `height`를 먼저 `long`으로 받은 뒤 곱한다. `(long)(w * h)`는 캐스팅 전에 넘친다.

## 문제 한 줄
`W × H` 격자를 대각선으로 잘랐을 때, 선이 지나지 않은 1×1 칸의 개수. `W`, `H`는 1억 이하.

## 핵심 패턴
```text
gcd = Gcd(W, H)
잘리는 칸 = W + H - gcd
사용 가능 = W * H - 잘리는 칸
```

```csharp
long width = w;
long height = h;
long brokenCount = width + height - Gcd(width, height);
return width * height - brokenCount;
```

서로소 블록으로 다시 세면 `g * (W/g + H/g - 1) = W + H - g`다. `(0,0)`에서 `(W, H)`까지 양 끝을 포함한 격자점 수는 `gcd + 1`이다.

| W | H | 사용 가능 | 확인 |
|---|---|---|---|
| 1 | 1 | 0 | 한 칸을 대각선이 가른다 |
| 1 | 5 | 0 | 폭이 1이면 모든 칸을 지난다 |
| 8 | 12 | 80 | 잘리는 칸 16 |

가로가 1인데 0이 아니면 빼는 식이 한 칸 어긋난 것이다.
