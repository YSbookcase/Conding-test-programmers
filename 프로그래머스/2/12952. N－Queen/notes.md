## 막혔던 지점
- 한 칸 두고 금지 칸을 보는 그림은 맞다. 세는 것은 가장 많이 넣는 개수가 아니라, 퀸 n개를 끝까지 둔 경우의 수다. 한 줄에 둘 곳이 없으면 그 줄기는 세지 않고, 바로 위 퀸의 다음 열을 시도한다.
- 퀸은 같은 행을 공격한다. n개를 두려면 한 행에 하나다. `cols[row] = col`은 그 행의 퀸이 `col`열에 있다는 뜻이다.
- `[1, 3, 0, 2]`는 `(0,1)`, `(1,3)`, `(2,0)`, `(3,2)`다. n=4의 다른 하나는 `[2, 0, 3, 1]`이다.
- `IsSafe`는 개수를 세지 않는다. 위에 둔 퀸과 열, 대각선이 겹치는지만 본다. 개수는 `Place`가 센다. `row == n`이면 `count`를 1 올리고, 그 호출이 끝나면 `for`가 다음 열로 가서 다른 배치도 본다.
- 같은 행의 다른 열은 그 `Place(row)` 안의 `for`다. `row`는 그 호출 동안 그대로이고 `col`만 0부터 `n - 1`까지 바뀐다. `Place(row + 1)`이 반환되면 그 `for`의 다음 열이다. 같은 행에 퀸 두 개를 동시에 두지 않는다.
- `solution`은 `Place(n, 0)`을 한 번 부른다. `Place(1)`은 0행에 둔 열마다 다시 호출된다.
- 처음에 본 `Place`는 `solution` 안의 지역 함수였다. 바깥 지역 변수를 그대로 본다. 제출본은 클래스 메서드라 `count`, `cols`를 필드로 두었다. 그래서 `IsSafe(int row, int col)`에 배열을 넘기지 않아도 된다. `Place`가 `cols[row] = col`로 쓴 값을 `IsSafe`가 읽는다. 하노이에서 `moves`를 넘긴 것은 그때 목록이 `solution` 안의 지역 변수였기 때문이다.
- 재귀에서 돌아온 뒤 `cols[row]`를 지우지 않아도 된다. `IsSafe`는 지금 행보다 위만 보고, 다음 열을 둘 때 그 칸을 덮어 쓴다. 열 사용을 `bool`로 표시하는 방식으로 바꾸면, 돌아온 뒤 그 표시를 해제해야 다음 배치가 그 열을 쓸 수 있다. 해제를 빼면 개수가 줄어든다.
- 대각선은 `Math.Abs(cols[prev] - col) == row - prev` 하나다. 행 차이와 열 차이가 같으면 양쪽 대각선이다. `(0,1)`과 `(2,3)`은 차이가 둘 다 2이고, `(0,2)`와 `(1,1)`은 차이가 둘 다 1이다.
- 동시에 쌓이는 깊이는 `Place(0)`부터 `Place(n)`까지라 최대 13이다. 열 시도가 많아도 이전 `Place(row + 1)`이 반환된 뒤에 다음 열로 간다.
- `solution`마다 `count = 0`, `cols = new int[n]`이 필요하다. 필드는 호출이 끝나도 남아서, 이 두 줄이 없으면 이전 테스트의 개수가 다음 답에 더해진다.
- n=1부터 8까지는 1, 0, 0, 2, 10, 4, 40, 92다. 제출 전에 볼 값은 n=2의 0과 n=4의 2다. 첫 행의 왼쪽 절반만 세고 두 배를 하면, 좌우가 똑같은 배치가 두 번 들어간다.
- 답을 배열에 넣어 두고 꺼내는 쪽이 실행은 더 짧다. n이 12 이하라 가능한 답이 12개다. 제출한 재귀는 226.58 ms로 통과했다.

## 문제 한 줄
n×n 체스판에 퀸 n개를 서로 공격하지 않게 두는 방법의 수. n은 12 이하의 자연수. 퀸은 행, 열, 대각선으로 이동한다.

## 핵심 패턴
```text
cols[row] = 그 행의 열
Place(row)
  row == n이면 count++
  아니면 col을 0부터 n-1까지
    위 행과 열이 같거나 |열 차이| == 행 차이면 건너뜀
    cols[row] = col
    Place(row + 1)
첫 호출은 Place(0)
solution 시작마다 count = 0, cols = new int[n]
```

```csharp
if (row == n)
{
    count++;
    return;
}

for (int col = 0; col < n; col++)
{
    if (!IsSafe(row, col))
        continue;

    cols[row] = col;
    Place(n, row + 1);
}
```

- `4` → `2`. 배치는 `[1, 3, 0, 2]`, `[2, 0, 3, 1]`
- `2` → `0`
- `1` → `1`

## 대안별 구현 비교

n이 1 이상 12 이하이면 A와 B의 답은 같다. A는 배치를 세고, B는 그 개수가 적힌 칸을 읽는다.

| 방법 | 하는 일 | n이 12일 때 |
|---|---|---|
| A. 행마다 열 시도 | 안전한 칸만 다음 행으로. 제출본 | 226.58 ms. 깊이는 13 |
| B. 답 배열 | `answer[n]` 한 칸 | 배치 계산이 없다. 인덱스 12가 끝 |

### B. 답 배열

```csharp
int[] answer = { 0, 1, 0, 0, 2, 10, 4, 40, 92, 352, 724, 2680, 14200 };
return answer[n];
```

인덱스가 n이다. `answer[4]`는 2, `answer[12]`는 14200이다. 13부터는 이 배열에 칸이 없다.

## 다음에 볼 것
- 백지에서는 필드 `cols`와 `Place(0)`만 먼저 적는다. `row == n`에서 개수를 올린 뒤, 같은 `for`가 다음 열을 계속 보게 둔다.
- n=2가 0이고 n=4가 2이면 열과 대각선 검사는 맞은 것이다.
- 열을 `bool`로 표시하면 재귀에서 돌아온 뒤 해제한다. 지금 제출본은 `cols[row]`를 덮어 쓰므로 해제가 없다.
