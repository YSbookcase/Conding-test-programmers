# 행렬 테두리 회전하기 (77485)

## 상태
- 제출 완료. 정확성 100, 합계 100. 메모리 48.3 MB, 시간 8.82 ms
- 제출 파일: `프로그래머스/2/77485. 행렬 테두리 회전하기/행렬 테두리 회전하기.cs`
- 2021 Dev-Matching. `solution`에서 행렬을 채운 뒤 쿼리마다 `Rotate`를 호출해 제출

## 내가 한 질문
- 행렬을 만들고, 만든 함수를 `queries` 개수만큼 돌린 뒤 결과를 `int` 배열에 담으면 되나

## 막혔던 지점
- 회전은 직사각형 안 전체가 아니다. `x1,y1`부터 `x2,y2`의 테두리만 시계로 한 칸 밀고, 안쪽은 그대로 둔다.
- 답은 행렬 전체가 아니라, 그 회전에서 위치가 바뀐 숫자 중 최솟값이다. 쿼리마다 하나씩 `answer`에 넣는다.
- 다음 쿼리는 이미 돌린 `board` 위에서 이어간다. 매 쿼리마다 새 행렬을 만들지 않는다.
- 인덱스를 1부터 `rows`, `columns`까지 쓰면 쿼리 값을 그대로 `Rotate`에 넣을 수 있다. `(i, j)`의 초기값은 `(i - 1) * columns + j`다.
- 시계로 밀 때 칸을 덮어쓰지 않게, `previous`에 이전 값을 들고 위→오른→아래→왼 순으로 넣는다. 시작 칸 `(x1, y1)`에는 왼쪽 변이 끝날 때 마지막 `previous`가 들어간다.

## 문제 한 줄
1부터 채운 `rows × columns` 행렬에서 쿼리마다 테두리를 시계로 한 칸 돌리고, 움직인 숫자의 최솟값을 순서대로 반환한다.

## 핵심 패턴
```text
board를 1부터 채운다
queries마다
  테두리만 시계로 한 칸 민다
  움직인 값의 최솟값을 answer에 넣는다
answer 반환
```

```csharp
int previous = board[x1, y1];
int minValue = previous;
// 위: 왼 -> 오, 오른: 위 -> 아래, 아래: 오 -> 왼, 왼: 아래 -> 위
// 각 칸: current를 빼고 previous를 넣고, previous = current, min 갱신
```

| rows | columns | queries | result |
|---|---|---|---|
| 6 | 6 | `[[2,2,5,4], ...]` | `[8, 10, 25]` |
| 3 | 3 | 네 번의 2×2 | `[1, 1, 5, 3]` |
| 100 | 97 | 전체 테두리 한 번 | `[1]` |

`rows`, `columns`는 100, 쿼리는 1만 번이라 테두리만 돌려도 충분하다.

## 다음에 볼 것
- 네 변 루프의 시작을 `y1+1`, `x1+1`, `y2-1`, `x2-1`로 두면 모서리를 두 번 쓰지 않는다.
- 제출본의 `previous`는 바로 앞 칸에서 밀려 온 값이고, `minValue`는 그 회전에서 본 테두리 값의 최솟값이다.
