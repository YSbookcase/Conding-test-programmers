# 특별한 이차원 배열 1 (181833)

## 내가 한 질문
- 2중 for로 단위 행렬을 채우는 풀이 외에 다른 방법이 있는가?
- `int[,]`와 다차원 배열 관련 메서드(`GetLength` 등)는 어떻게 쓰나?
- `int[,]`로 `[n, 2n]`처럼 쓸 수 있는가? 행마다 길이를 다르게 할 수 있는가?
- 가변 배열(`int[][]`) 선언이 왜 특이한가?
- 수학적으로는 같아도 사용 측면에서는 다른가?
- 3차원으로 확장해도 비슷한가? 실무에서 고차원은 어디까지 쓰나?

## 막혔던 지점 및 개념 정리
- **문제 본질**: `n × n` 단위 행렬(identity matrix) 만들기. `i == j`면 1, 아니면 0.
- **`int` 배열 기본값**: `new int[n, n]`은 전부 0으로 초기화되므로, 대각선만 `result[i, i] = 1`로 두면 충분. `i != j`일 때 0을 대입할 필요 없음.
- **`int[,]` vs `int[][]` (수학 개념 vs C# 타입)**:
  - 수학적으로는 둘 다 2차원 구조에 가깝지만, C#에서는 **서로 다른 타입**이며 자동 변환되지 않음.
  - `int[,]`: 직사각형(rectangular). 모든 행의 열 수가 동일. 접근 `arr[i, j]`.
  - `int[][]`: 가변 배열(jagged). 배열의 배열. 행마다 길이 다를 수 있음. 접근 `arr[i][j]`.
- **`[n, 2n]`은 가능한가?**:
  - ⭕ `new int[n, 2 * n]` → n행 × 2n열 **직사각형**이라 `int[,]`로 가능.
  - ❌ 행마다 열 개수가 다른 형태는 `int[,]` 불가 → `int[][]` 사용.
- **가변 배열 선언이 특이한 이유**:
  - `new int[3][]`는 **바깥(행 슬롯)만** 만들고, 각 원소는 아직 `null`.
  - 각 행을 `jagged[i] = new int[길이];`로 **따로 `new`** 해야 함.
- **3차원 이상도 동일 패턴**:
  - 직사각형: `int[,,]` → `a[i, j, k]`
  - 가변: `int[][][]` → `a[i][j][k]` (단계별 `new` 필요)
  - 실무/코테는 보통 1~3차원, 드물게 4~5차원. 그 이상은 상태 압축(비트/해시/딕셔너리)으로 처리하는 경우가 많음.

## 핵심 코드

### 1. 대각선만 채우기 (최종 제출 ⭐)
```csharp
public class Solution {
    public int[,] solution(int n) {
        int[,] result = new int[n, n];

        for (int i = 0; i < n; i++) {
            result[i, i] = 1;
        }

        return result;
    }
}
```

### 2. 2중 for + 삼항 (의도가 더 명시적)
```csharp
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        result[i, j] = (i == j) ? 1 : 0;
    }
}
```

## `int[,]` 자주 쓰는 API
| API | 의미 |
|---|---|
| `arr.GetLength(0)` | 행 수 |
| `arr.GetLength(1)` | 열 수 |
| `arr.Length` | 전체 원소 개수 (행×열) |
| `arr.Rank` | 차원 수 (2차원 → 2) |
| `arr[i, j]` | 원소 접근 |

## `int[,]` vs `int[][]` 비교
| | `int[,]` | `int[][]` |
|---|---|---|
| **모양** | 직사각형 (n × m) | 계단형 (행마다 길이 다름) |
| **선언** | `new int[n, m]` 한 번 | `new int[n][]` + 각 행 `new` |
| **접근** | `arr[i, j]` | `arr[i][j]` |
| **예시** | `new int[n, 2*n]` (n행 2n열) | 0행 2칸, 1행 5칸 가능 |

## 다음에 볼 것
- 고정 `n × n` / `n × m` → **`int[,]`**, 행마다 길이 다름 → **`int[][]`**
- 단위 행렬은 **대각선만 1**로 두면 충분 (`int` 기본값 0 활용)
- 고차원은 3차원까지 익히고, 5차원 이상은 상태 압축을 우선 고려
