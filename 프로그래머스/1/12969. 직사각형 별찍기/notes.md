# 직사각형 별찍기 (12969)

## 상태
- 제출 완료. 한 줄을 `new string('*', a)`로 만들어 세로 `b`번 출력
- 제출 파일: `프로그래머스/1/12969. 직사각형 별찍기/직사각형 별찍기.cs`
- LocalTest는 쓰지 않음

## 내가 한 질문
- 이게 레벨 1인가?
- 주의할 점이 있나?
- 별을 반복해서 출력하는 게 부담되지 않나?
- 한 글자씩 찍는 것과 한 줄씩 찍는 것은 차이가 없어 보인다.

## 막혔던 지점
- 첫 수가 가로 `a`, 둘째 수가 세로 `b`다. `5 3`을 바깥 5, 안쪽 3으로 돌리면 줄이 5개이고 한 줄의 별이 3개다.
- 별 사이에 공백이 없다. `WriteLine`은 한 줄이 끝난 뒤에 한 번이다. 안쪽에서 `WriteLine`을 하면 별이 한 개씩 세로로 나온다.
- 반환값이 없다. `Console`에 찍는다.
- 한 글자마다 `Write`하면 1000×1000에서 호출이 100만 번이다. 이 제한에서는 한 줄씩 찍어도 통과하고, 시간 차이는 없다.

## 문제 한 줄
가로 `n`, 세로 `m`인 별 직사각형을 출력한다.

## 핵심 패턴
```text
a = 첫 수(가로), b = 둘째 수(세로)
b번: 길이 a인 "*****" 를 한 줄로 출력
```
- 입력 `5 3` → 별 5개짜리 줄이 3줄.
- `n`, `m`은 1000 이하. 별은 최대 100만 개.

## 대안별 구현 비교

출력은 같다. 차이는 `Write` 호출 횟수다. 이 제한에서는 둘 다 충분하다.

### A. 한 줄을 한 번에
제출한 버전. 호출은 세로 길이만큼이다.

```csharp
for (int i = 0; i < b; i++)
{
    Console.Write(new string('*', a));
    Console.WriteLine();
}
```

`Console.WriteLine(new string('*', a))`도 같다.

### B. 별 하나를 반복
호출은 가로×세로마큼이다. `5 3`의 출력 형태는 A와 같다.

```csharp
for (int i = 0; i < b; i++)
{
    for (int j = 0; j < a; j++)
    {
        Console.Write('*');
    }
    Console.WriteLine();
}
```

## 다음에 볼 것
- 첫 수가 가로다. 반복 순서를 바꾸면 직사각형이 돌아간다.
- 이 크기의 출력은 한 글자씩이어도 된다.
