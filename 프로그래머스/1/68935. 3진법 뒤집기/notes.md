# 3진법 뒤집기 (68935)

## 상태
- 제출 완료. 3으로 나눈 나머지를 꺼내면서 뒤집힌 3진수의 값을 바로 계산
- 제출 파일: `프로그래머스/1/68935. 3진법 뒤집기/3진법 뒤집기.cs`

## 내가 한 질문
- 3진법 전환은 수학적으로 풀어야 하는가?
- `int`는 10^9 정도까지 아닌가? 3진수가 최대 17자리면 들어가지 않는 것 아닌가?
- 3진 표기를 17자리 정수처럼 붙이면 `int`에 안 들어가지 않는가?
- 문자열로 구하는 방법도 보고 싶다.

## 막혔던 지점
- 3으로 나눌 때 나머지는 낮은 자리부터 나온다. 원래 3진수는 나머지를 거꾸로 읽지만, 문제에서 원하는 것은 뒤집힌 3진수이므로 나머지가 나온 순서를 그대로 쓰면 된다.
- 17자리는 10진수 17자리가 아니라 3진수 17자리다. `3^16 = 43,046,721`, `3^17 = 129,140,163`이므로 입력 최댓값 100,000,000은 3진수로 최대 17자리다.
- 3진수에는 0, 1, 2만 온다. `333...`은 유효한 3진수가 아니다. 17자리 3진수의 이론상 최댓값은 `22222222222222222(3) = 3^17 - 1 = 129,140,162`라 `int`에 들어간다.
- `22222222222222222`라는 자릿수 모양을 10진 정수처럼 저장하려 하면 17자리라 `int`에 안 들어간다. 제출 풀이는 이 표기를 저장하지 않고 `answer = answer * 3 + digit`으로 실제 값을 바로 계산한다.
- 정수 변수에는 3진수나 10진수라는 속성이 없다. 값만 저장되고, 출력할 때 보통 10진수로 표시한다.
- 문자열 `"0021"`을 `int.Parse`하면 3진수 7이 아니라 10진수 21로 해석된다. 3진수 값은 각 자리에서 `answer * 3 + digit`으로 계산해야 한다.
- C#의 `Convert.ToString(value, base)`는 2, 8, 10, 16진법만 지원한다. 3진법은 직접 나눗셈으로 만들어야 한다.

## 문제 한 줄
자연수를 3진수로 바꿔 자릿수를 뒤집은 뒤, 그 값을 10진 정수로 반환한다.

## 핵심 패턴
```text
answer = 0
n > 0 동안
  digit = n % 3
  answer = answer * 3 + digit
  n /= 3
return answer
```

45를 3으로 나눈 나머지는 `0, 0, 2, 1` 순서다. 이는 뒤집힌 3진수 `0021`이고, 누적 계산은 `0 → 0 → 2 → 7`이다.

시간 O(log₃ n), 추가 메모리 O(1).

## 제출 코드
```csharp
int answer = 0;

while (n > 0)
{
    answer = answer * 3 + n % 3;
    n /= 3;
}

return answer;
```

`n % 3`은 현재 가장 낮은 3진수 자리다. `answer * 3`은 지금까지 만든 3진수의 자릿수를 한 칸 왼쪽으로 옮기고, 나머지를 마지막 자리에 붙이는 계산이다.

## 대안별 구현 비교

둘 다 나머지가 나오는 순서를 뒤집힌 3진수로 사용한다. 제출한 A는 중간 표기를 만들지 않는다.

### A. 값으로 바로 계산
```csharp
int answer = 0;
while (n > 0)
{
    answer = answer * 3 + n % 3;
    n /= 3;
}
return answer;
```

### B. 문자열로 뒤집힌 3진수 보관
```csharp
StringBuilder reversedTernary = new StringBuilder();

while (n > 0)
{
    reversedTernary.Append(n % 3);
    n /= 3;
}

int answer = 0;
foreach (char digit in reversedTernary.ToString())
    answer = answer * 3 + (digit - '0');

return answer;
```

B는 45일 때 `"0021"`을 직접 확인할 수 있어 이해하기 쉽다. `StringBuilder`와 문자열 할당이 필요하고 `using System.Text;`를 추가해야 한다. `int.Parse(reversedTernary.ToString())`는 진법 해석이 달라서 사용할 수 없다.

## 다음에 볼 것
- 진법 변환의 나머지는 낮은 자리부터 나온다.
- 자릿수 표기와 그 표기가 나타내는 실제 값을 구분한다.
- `answer = answer * base + digit`은 해당 진법의 자릿수를 실제 값으로 누적하는 패턴이다.
