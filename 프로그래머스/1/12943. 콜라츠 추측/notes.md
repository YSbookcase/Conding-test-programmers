# 콜라츠 추측 (12943)

## 상태
- 제출 완료. 수는 `long`, 횟수는 `int`. 1이면 횟수, 500번 안에 아니면 `-1`
- 제출 파일: `프로그래머스/1/12943. 콜라츠 추측/콜라츠 추측.cs`
- LocalTest는 쓰지 않음

## 내가 한 질문
- 홀수면 `3 * n + 1`로 수가 너무 커지지 않나?
- 1이 되면 0을 반환하라고 하지 않았나?
- 추가로 주의할 점이 있나?

## 막혔던 지점
- 입력은 800만 미만이지만 중간 값은 `int` 최대 약 21억을 넘는다. `626331`은 104번째 근처에 약 72억까지 올라가고, 500번 안에 1이 되지 않아 `-1`이다. 예제만 보면 `int`로도 `-1`이라 넘어간다.
- `113383`은 247번 만에 1이 되는데 중간에 약 24억이 나온다. `int`로 계산하면 값이 깨져 `-1`이 된다. 식에서만 `(long)`을 붙이고 다시 `int`에 넣어도 잘린다. 수 변수 자체가 `long`이어야 한다.
- 「주어진 수가 1」일 때만 0이다. 작업을 해서 1이 되면 그 횟수다. 6은 8, 16은 4다. 1이 된 순간 0을 반환하면 예제가 전부 0이다.
- 입력이 1이면 반복에 들어가지 않아 `stepCount`가 0이다. 1을 홀수로 처리하면 `4`가 되어 횟수가 늘어난다.
- 500번째 작업으로 1이 되면 500이다. 횟수가 500인지만 먼저 보고 `-1`을 반환하면 그 경우가 빠진다.
- `3 * n + 1`의 결과는 항상 짝수다. 이어서 2로 나누는 것까지 한 번으로 묶으면 6의 횟수가 8보다 작아진다.

## 문제 한 줄
짝수면 2로 나누고, 홀수면 `3 * n + 1` 한다. 1이 될 때까지의 횟수. 입력이 1이면 0, 500번 안에 안 되면 `-1`.

## 핵심 패턴
```text
current = (long)num, stepCount = 0
current != 1 이고 stepCount < 500 인 동안:
  짝수면 current /= 2
  홀수면 current = current * 3 + 1
  stepCount++
current == 1 이면 stepCount, 아니면 -1
```
- 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1. 8번.
- 16 → 8 → 4 → 2 → 1. 4번.
- 반복은 최대 500번. 이 제한의 중간 값은 `long`에 들어간다.

## 대안별 구현 비교

수를 `long`으로 유지하고 작업을 한 번에 하나씩 하면 결과가 같다. `int`로 넘기거나, 1이 되면 무조건 0을 반환하거나, 홀수 다음 나누기까지 한 번에 하면 달라진다.

### A. `long`으로 세며 끝난 뒤 1인지 확인
제출한 버전. 입력이 1이면 반복을 건너뛰어 0이다.

```csharp
long current = num;
int stepCount = 0;
while (current != 1 && stepCount < 500)
{
    if (current % 2 == 0)
    {
        current /= 2;
    }
    else
    {
        current = current * 3 + 1;
    }

    stepCount++;
}

if (current == 1)
{
    return stepCount;
}

return -1;
```

### B. `int`에 다시 넣기
`113383`의 중간 약 24억이 잘린다. 1까지 247번인데 `-1`이 될 수 있다. `626331`은 원래 `-1`이라 예제만으로는 안 드러난다.

```csharp
int current = num;
current = (int)((long)current * 3 + 1);
```

### C. 1이 되면 0
6과 16도 0이 된다. 0은 입력이 이미 1일 때의 횟수다.

```csharp
if (current == 1)
{
    return 0;
}
```

### D. 홀수 작업과 다음 나누기를 한 번으로
`3 * n + 1`은 짝수라 바로 2로 나눌 수 있지만, 문제의 횟수는 두 번이다. 6이 8보다 작아진다.

```csharp
current = (current * 3 + 1) / 2;
stepCount++;
```

## 다음에 볼 것
- 입력 제한과 중간 값의 제한은 다르다. 횟수 상한이 있어도 곱하는 도중 `int`를 넘을 수 있다.
- 1이 된 뒤의 반환은 횟수다. 0은 작업을 하지 않은 입력 1뿐이다.
