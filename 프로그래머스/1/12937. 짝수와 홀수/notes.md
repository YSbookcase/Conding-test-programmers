## 막혔던 지점
- `num == 0` 분기는 없어도 된다. `0 % 2`가 0이라 짝수 조건과 같다. 0은 짝수다.
- `answer = ""`는 다음 분기에서 항상 다시 넣으므로 결과에 쓰이지 않는다. 양쪽에서 모두 넣으면 미리 빈 문자열을 두지 않아도 된다.
- 지금 코드는 음수에서도 맞다. `-4 % 2`는 0이라 `"Even"`이다. `-3 % 2`는 1이 아니라 -1이라 짝수 조건에 안 들어가고 `"Odd"`가 된다.
- 홀수를 `num % 2 == 1`로 보면 `-3`이 빠진다. 나머지는 -1이다.
- 반환 문자열은 `"Even"`, `"Odd"`와 대소문자가 같아야 한다. `"even"`은 다른 문자열이다.

## 문제 한 줄
짝수면 `"Even"`, 홀수면 `"Odd"`. 0은 짝수다.

## 핵심 패턴
```text
num % 2 == 0 이면 "Even"
아니면 "Odd"
```
- 3 → `"Odd"`, 4 → `"Even"`, 0 → `"Even"`
- `-3` → `"Odd"`, `-4` → `"Even"`
- `num`은 `int` 전체. 반복은 없다.

## 대안별 구현 비교

짝수를 `== 0`으로 보고 나머지를 홀수로 두면 결과가 같다. 홀수를 `== 1`로 보면 음수에서 달라진다.

### A. 짝수만 `== 0`, 나머지는 홀수
제출한 버전.

```csharp
string answer;
if (num % 2 == 0)
{
    answer = "Even";
}
else
{
    answer = "Odd";
}
return answer;
```

바로 반환해도 같다.

```csharp
if (num % 2 == 0)
{
    return "Even";
}
return "Odd";
```

### B. 0을 따로 봄
0도 A의 짝수 조건에 들어간다. 결과는 같고 분기가 겹친다.

```csharp
if (num == 0)
{
    answer = "Even";
}
if (num % 2 == 0)
{
    answer = "Even";
}
```

### C. 홀수를 `== 1`로 확인
`-3 % 2`는 -1이라 홀수인데도 `"Even"`이 된다. 0과 양수는 A와 같다.

```csharp
if (num % 2 == 1)
{
    return "Odd";
}
return "Even";
```

## 다음에 볼 것
- C#에서 음수를 나눈 나머지 부호는 나누어지는 수를 따른다. `-3 % 2`는 -1이다.
- 홀수 조건은 `== 1`보다, 짝수가 아닌 쪽으로 둔다.
