# 문자열을 정수로 바꾸기 (12925)

## 상태
- 제출 완료. `int.Parse(s)`
- 제출 파일: `프로그래머스/1/12925. 문자열을 정수로 바꾸기/문자열을 정수로 바꾸기.cs`
- LocalTest는 쓰지 않음

## 내가 한 질문
- `TryParse`나 `Parse`만으로는 안 되고 `'-'`를 따로 빼서 확인해야 하나?
- 음수 부호도 판별해 주는 것은 몰랐다.
- `TryParse`도 부호 판별이 되나?
- 사람이 넣는 값에는 `Parse`가 터지니까 `TryParse`가 더 일반적이지 않나?

## 막혔던 지점
- `int.Parse`가 맨 앞의 `'-'`와 `'+'`를 부호로 읽는다. 따로 떼지 않아도 `"-1234"`는 `-1234`, `"+1234"`는 `1234`다. 부호가 없으면 양수다.
- `TryParse`도 같은 부호 규칙을 쓴다. 실패하면 예외 대신 `false`를 주고, 값은 `out`에 담긴다. 이 문제는 잘못된 문자열이 없다고 해서 `Parse`와 결과가 같다.
- 사람이 입력한 문자열은 빈 칸, 글자, 부호가 두 번인 경우가 있어 `Parse`가 예외를 낸다. 그때는 `TryParse`로 `false`를 받아 다시 받는다. 이 문제는 부호와 숫자만 오고 잘못된 값은 없다.
- 길이는 1 이상 5 이하라 `int`에 들어간다. `"0"`으로 시작하지 않는다.

## 문제 한 줄
부호와 숫자로 된 문자열을 `int`로 바꾼다.

## 핵심 패턴
```text
return int.Parse(s)
```
- `"1234"` → `1234`
- `"-1234"` → `-1234`

## 대안별 구현 비교

이 문제의 입력에서는 결과가 같다. 잘못된 문자가 있으면 `Parse`만 예외가 난다. 부호를 직접 쌓아도 예제와 같다.

### A. `int.Parse`
제출한 버전. 맨 앞 `+`, `-`를 부호로 읽는다.

```csharp
return int.Parse(s);
```

### B. `int.TryParse`
부호 규칙은 A와 같다. 실패하면 `false`다. 잘못된 값이 없는 이 문제에서는 A와 같은 수를 반환한다.

```csharp
int.TryParse(s, out int number);
return number;
```

### C. 부호를 기억하고 자릿수를 쌓음
`Parse`가 하는 일을 직접 쓴 것이다. `'-'`면 나중에 `-1`을 곱한다. `'+'`와 숫자는 자릿수로 쌓는다. `"1234"`는 `1234`, `"-1234"`는 `-1234`다.

```csharp
int sign = 1;
int start = 0;
if (s[0] == '-')
{
    sign = -1;
    start = 1;
}
else if (s[0] == '+')
{
    start = 1;
}

int number = 0;
for (int i = start; i < s.Length; i++)
{
    number = number * 10 + (s[i] - '0');
}
return number * sign;
```

## 다음에 볼 것
- `Parse`와 `TryParse`는 둘 다 맨 앞 부호를 읽는다. 차이는 잘못된 문자열에서 예외냐 `false`냐다.
- 사람 입력은 `TryParse`. 형식이 보장된 값만 `Parse`로 넣는다.
