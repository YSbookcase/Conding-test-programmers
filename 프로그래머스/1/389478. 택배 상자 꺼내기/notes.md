## 문제 한 줄
지그재그로 쌓인 상자에서 `num`과 **같은 열**의 위 상자(+ 자신)를 몇 개 꺼내야 하는지.

## 핵심
```text
row = (num - 1) / w
order = (num - 1) % w
col = 짝수층 ? order : (w - 1 - order)
```
- 매 층 가로는 항상 `0 ~ w-1`. 층이 높아져도 col이 w를 넘지 않음.
- 짝수: 왼→오 / 홀수: 오→왼 (`w-1-…` 반전)

### (r, col) → 상자 번호
```text
start = r * w + 1
짝수: start + col
홀수: start + (w - 1 - col)
번호가 n 이하면 그 칸에 상자 있음
```

## 시행착오
- **층 차이만** `(maxRow - row) + 1` → 맨 위가 덜 찬 열은 빈 칸인데도 셈 → 예: n=22,w=6,num=1은 정답 3인데 4가 됨.
- 빈 칸은 **맨 위 층에만** 생김(아래는 가득). 그래서 층 차이 후 맨 위 col 없으면 -1도 가능(방식 B).
- 방식 A: 위층 루프에서 `box <= n`일 때만 +1 → 빈 칸·번호 모두 자연스럽게 처리. 반복 ≤ 대략 `n/w`.

## 방식 비교
| | A 위층 루프 | B 층 차이 ±1 |
|--|-------------|--------------|
| 확장·실수 | 유리 | 맨 위 조건 조심 |
| 복잡도 | O(층 수) | O(1) |
| 이 문제 | 둘 다 충분 | 둘 다 충분 |

학습·확장성 측면에서는 **A 권장**.
