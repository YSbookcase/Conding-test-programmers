## 막혔던 지점
- 큰 수를 미리 고르지 않아도 된다. 작은 수를 큰 수로 나누면 나머지가 작은 수 자신이라 다음 단계에서 둘이 바뀐다. `3 % 12`는 `3`이라 다음이 `gcd(12, 3)`이다. `12`를 먼저 넣어도 `12 % 3`이 `0`이라 최대공약수는 `3`이다.
- 최소공배수는 `n / 최대공약수 * m`이다. `n / gcd`는 항상 나누어 떨어진다. 두 수는 100만 이하라 곱을 먼저 하면 `int`를 넘을 수 있다. `(long)n / gcd * m`처럼 나누기를 먼저 한다.
- 서로소이고 둘 다 100만에 가까우면 최소공배수가 1조에 가깝다. `int` 최대값은 약 21억이라 `(int)lcm`에 담기지 않는다. 예제 `2, 5`의 10은 들어간다. 반환이 `int[]`라 그 큰 경우는 잘린다.

## 문제 한 줄
최대공약수와 최소공배수를 `[최대공약수, 최소공배수]`로 반환한다.

## 핵심 패턴
```text
b != 0 인 동안:
  remain = a % b
  a = b
  b = remain
최대공약수 = a
최소공배수 = (long)n / 최대공약수 * m
```
- `3, 12` → `[3, 12]`
- `2, 5` → `[1, 10]`
- 반복은 수가 줄어드므로 100만에서도 충분하다.

## 대안별 구현 비교

호제법과 나누기 먼저인 최소공배수는 예제와 같다. 곱을 `int`로 먼저 하면 결과가 `int`에 들어가는 쌍에서도 깨질 수 있다. 크기 비교를 앞에 두어도 최대공약수는 같다.

### A. 나머지 반복, 나누기 먼저
제출한 버전. `Gcd`는 `solution`과 같은 클래스 안에 있다.

```csharp
int gcd = Gcd(n, m);
long lcm = (long)n / gcd * m;
return new int[] { gcd, (int)lcm };

int Gcd(int a, int b)
{
    while (b != 0)
    {
        int remain = a % b;
        a = b;
        b = remain;
    }

    return a;
}
```

### B. 큰 수를 먼저 고름
`3, 12`와 `12, 3` 모두 최대공약수가 `3`이다. A가 나머지에서 순서를 바꾸므로 이 비교는 없어도 된다.

```csharp
if (n < m)
{
    int temp = n;
    n = m;
    m = temp;
}
```

### C. 곱을 먼저 `int`로
`n * m`이 `int`를 넘으면, 최소공배수가 `int`에 들어가도 이미 깨진 값이다. `(long)(n * m) / gcd`도 곱이 먼저 `int`다.

```csharp
int lcm = n * m / gcd;
```

`(long)n * m / gcd`는 첫 곱부터 `long`이라 A와 같다. A는 나누기를 먼저 해서 중간 값이 더 작다.

## 다음에 볼 것
- 호제법은 순서를 미리 맞추지 않는다. `a % b`가 다음 호출의 순서를 바꾼다.
- 곱이 넘칠 수 있으면 나누어 떨어지는 나눗셈을 먼저 하고, 그 곱을 `long`으로 한다.
