## 막혔던 지점
- 동작은 맞다. `12`는 `28`, `5`는 `6`이다.
- `i`는 `1`부터다. `0`으로 나머지를 구하면 예외다. `n`이 `0`이면 반복이 돌지 않아 합은 `0`이다.
- `n % i == 0`이면 `i`와 `n / i`가 짝이다. `12`는 `1`과 `12`, `2`와 `6`, `3`과 `4`다.
- 제곱수에서는 둘이 같다. `9`의 `3`을 둘 다 더하면 `3`이 두 번이다. `i * i == n`이면 `i`만 더하는 분기를 먼저 둔다. `%`만 남기면 중복된다.
- `1`부터 `n`까지 나눠도 답은 같다. `n`이 `3000` 이하라 그 반복도 통과한다. 제곱근까지가 나누는 횟수가 적다. `12`는 약 3번, `3000`은 약 55번이다.
- 조건과 `if`에서 `i * i`를 두 번 해도 이 크기에서는 차이가 없다. `int square = i * i`로 한 번 담아도 합은 같다. `i * i`는 이 범위에서 `int`를 넘지 않는다.

## 문제 한 줄
`n`의 약수를 모두 더한 값을 반환한다. `n`은 0 이상 3000 이하.

## 핵심 패턴
```text
i = 1부터 i * i <= n 까지
  i * i == n 이면 sum += i
  n % i == 0 이면 sum += i + n / i
```
- `12` → `1+12+2+6+3+4` = `28`
- `5` → `1+5` = `6`
- `9` → `1+9+3` = `13`
- `0` → `0`

## 대안별 구현 비교

제곱수에서 한 번만 더하면 결과가 같다. 제곱수인데 짝을 둘 다 더하면 `9`가 `16`이 되어 다르다. `1`부터 `n`까지 보는 쪽은 합이 같고 반복만 많다.

### A. 제곱근까지, 제곱수는 한 번
제출한 버전.

```csharp
int sum = 0;
for (int i = 1; i * i <= n; i++)
{
    if (i * i == n)
    {
        sum += i;
    }
    else if (n % i == 0)
    {
        sum += i;
        sum += n / i;
    }
}
return sum;
```

`square`를 한 번만 계산해도 같다.

```csharp
int square = i * i;
if (square > n)
{
    break;
}
```

### B. `1`부터 `n`까지
`12`는 `28`, `5`는 `6`으로 A와 같다. 나누는 횟수가 `n`번이다.

```csharp
int sum = 0;
for (int i = 1; i <= n; i++)
{
    if (n % i == 0)
    {
        sum += i;
    }
}
return sum;
```

`n`이 `0`이면 이 반복도 돌지 않아 `0`이다.

### C. 제곱수인데 짝을 둘 다 더함
`9`의 약수 합이 `1 + 9 + 3 + 3`인 `16`이 된다. A는 `13`이다.

```csharp
if (n % i == 0)
{
    sum += i;
    sum += n / i;
}
```

## 다음에 볼 것
- 약수는 제곱근까지만 봐도 짝이 나온다. 제곱근 자체는 한 번만 더한다.
- 반복은 `1`부터다. `0`으로 나누지 않는다.
