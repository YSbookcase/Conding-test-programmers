## 막혔던 지점
- 6480은 각 자리를 “없음 또는 A~U”로 독립 선택한다. 가운데가 빈 `A _ E` 같은 문자열까지 들어간다. 사전에는 길이 1~5인 **이어진 단어**만 있다. `5 + 25 + 125 + 625 + 3125 = 3905`.
- “안 들어감”은 자리마다 고르는 선택이 아니라, 그 길이에서 단어가 끝나는 것이다.
- 자릿값의 가중치는 “이 자리에서 모음을 하나 건너뛸 때 DFS가 지나가는 단어 수”다. 첫 자리면 `A`로 시작하는 단어 `1+5+25+125+625 = 781`개다. 각 글자에서 앞 모음 개수 × 가중치를 더하고, 그 글자까지 만든 단어에 `+1`한다.
- `vowels.IndexOf`는 그 글자가 `AEIOU` 중 몇 번째인지 보는 것이라 탐색은 모음 5개다.
- `"AE"`의 답은 **158**이다. 설명 중 제목을 `→ 7`로 적은 것은 실수였고, 7과 `"AE"`는 관계 없다.

## 문제 한 줄
`A E I O U`만 쓰는 길이 1~5 단어를 사전 순(`A`, `AA`, `AAA` …)으로 나열했을 때 `word`의 번호. 길이는 5 이하.

## 핵심 패턴 (DFS, 제출 방향)
```text
현재 문자열 길이가 5면 멈춤
모음 A E I O U를 하나씩 붙인다
  번호 +1
  붙인 단어가 word면 답이 그 번호
  그 단어에서 다시 붙인다
```

```csharp
int solution(string word)
{
    string vowels = "AEIOU";
    int order = 0;
    int answer = 0;

    void Dfs(string current)
    {
        if (current.Length >= 5)
            return;

        foreach (char vowel in vowels)
        {
            string next = current + vowel;
            order++;
            if (next == word)
                answer = order;
            Dfs(next);
        }
    }

    Dfs("");
    return answer;
}
```

`"AAAAE"` → `A, AA, AAA, AAAA, AAAAA, AAAAE` → 6.

## 대안별 구현 비교

답 번호는 같다. DFS는 사전을 그대로 만들고, 식은 자리마다 건너뛴 가지 크기만 더한다. 이 제한에서는 둘 다 충분하다. 제출은 DFS.

| 방법 | 계산 | 메모 |
|---|---|---|
| A. DFS | 최대 3905번 번호 부여 | 풀이·제출 방향. LocalTest |
| B. 자릿값 | 길이만큼 덧셈 | 가중치로 가지를 통째로 건너뜀 |

### B. 자릿값

가중치 = 그 자리에서 모음 하나 가지의 단어 수 = `(5^(5 - 자리) - 1) / 4`.

| 자리(0부터) | 가중치 | 구성 |
|---|---|---|
| 0 | 781 | `1+5+25+125+625` |
| 1 | 156 | `1+5+25+125` |
| 2 | 31 | `1+5+25` |
| 3 | 6 | `1+5` |
| 4 | 1 | `1` |

한 글자마다: `앞 모음 개수 × weights[index] + 1`.

```csharp
int solution(string word)
{
    string vowels = "AEIOU";
    int[] weights = { 781, 156, 31, 6, 1 };
    int answer = 0;

    for (int index = 0; index < word.Length; index++)
    {
        int vowelIndex = vowels.IndexOf(word[index]);
        answer += vowelIndex * weights[index] + 1;
    }

    return answer;
}
```

#### 예시 `"A"` → 1

```text
A → 0×781 + 1 = 1
```

#### 예시 `"AA"` → 2

```text
A +1 → 1
A +1 → 2
```

#### 예시 `"E"` → 782

```text
E → 앞 모음 A × 781 + 1 = 782
[A 가지 781개] 다음이 "E"
```

#### 예시 `"AE"` → 158

```text
A → 0×781 + 1 = 1
E → 앞 모음 A × 156 + 1 = 157
합 = 158
```

```text
1:     A
2~157: AA, AAA, … (두 번째가 A인 가지 156개)
158:   AE
```

`1 + 156 + 1 = 158`. 답이 7이 아니다.

#### 예시 `"AAAAE"` → 6

```text
A  0×781 + 1 = 1     ("A")
A  0×156 + 1 → 누적 2
A  0×31 + 1 → 누적 3
A  0×6 + 1 → 누적 4
E  1×1 + 1 → 누적 6
```

#### 예시 `"AAAE"` → 10

```text
A +1 → 1
A +1 → 2
A +1 → 3
E  앞 모음 A × 6 + 1 = 7 → 누적 10
```

#### 예시 `"I"` → 1563

```text
I → 앞 모음 A, E × 781 + 1 = 1563
[A 781] [E 781] 다음이 "I"
```

#### 예시 `"EIO"` → 1189

```text
E  1×781 + 1 = 782
I  2×156 + 1 = 313   누적 1095
O  3×31 + 1 = 94     누적 1189
```

```text
A…… (781)
E
├ EA…… (156)
├ EE…… (156)
└ EI
   ├ EIA… EIE… EII… (각 31)
   └ EIO → 1189
```

#### 예시 `"U"` → 3125

```text
U → 앞 모음 A E I O 네 개 × 781 + 1 = 3125
```
