## 막혔던 지점
- 숫자 내림차순은 그 수 하나의 값이다. `[6, 10, 2]`는 `10, 6, 2`가 되어 `"1062"`다. `6`을 앞에 둔 `"610"`이 `"106"`보다 크다. `[3, 30, 34, 5, 9]`는 `34, 30, 9, 5, 3`이라 `"3430953"`이다. 답은 `"9534330"`이다.
- 글자 내림차순도 다르다. `"30"`과 `"3"`은 첫 글자가 같고 `"30"`이 더 길어 `"30"`이 앞이다. `[3, 30, 34, 5, 9]`는 `"9534303"`이 된다.
- `[3, 30, 34]`만 보면 세 갈래가 맞다. `34`는 다음 자리 `4`가 커서 앞, `3`은 한 글자라 가운데, `30`은 다음 자리가 `0`이라 뒤다. 그 위치는 고정이 아니다.
- 다음 자리가 `0`이 아니어도 한 글자가 앞일 수 있다. `3`과 `32`는 `"332"`와 `"323"`이라 `3`이 앞이다. `2`가 `3`보다 작기 때문이다. `3`과 `34`는 `"343"`과 `"334"`라 `34`가 앞이다.
- 둘째 자리가 둘 다 `0`이어도 순서가 반대다. `10`과 `101`은 `"10110"`이 커서 `101`이 앞이다. `30`과 `301`은 `"30301"`이 커서 `30`이 앞이다. 남은 `1`을 각각 `10`의 맨 앞 `1`, `30`의 맨 앞 `3`과 비교한 결과다.
- 예제 `[6, 10, 2]`, `[3, 30, 34, 5, 9]`에는 이 쌍이 없다. 앞자리와 다음 자리만 나눠도 예제는 통과한다. 2021년 10월 20일에 추가된 테스트가 이런 쌍을 본다.
- `CompareTo`는 앞에서부터 한 글자씩 본다. `'0'`부터 `'9'`는 문자 코드도 그 순서다. 음수는 앞 문자열이 더 작고, `0`은 같고, 양수는 앞 문자열이 더 크다. `"330".CompareTo("303")`은 둘째 글자에서 양수다.
- 이어 붙이면 길이가 같아진다. `"3"`과 `"30"`을 그대로 비교하면 둘째 글자에서 한쪽이 끝나지만, `"330"`과 `"303"`은 둘 다 세 글자다.
- 이어 붙인 문자열이 같은 경우가 있다. 같은 수끼리는 `"10" + "10"`이 양쪽 다 `"1010"`이다. `1`과 `11`은 양쪽 다 `"111"`이다. `2`와 `22`, `1`과 `111`도 같다. 순서를 바꿔도 최종 문자열이 같아서 정렬이 둘을 같은 크기로 봐도 답은 같다. `3`과 `30`은 `"330"`과 `"303"`이라 같지 않다.
- `Array.Sort`는 비교 결과가 음수인 쪽을 앞에 둔다. `(second + first).CompareTo(first + second)`라야 더 큰 결합이 앞에 온다. `first`가 `"3"`, `second`가 `"30"`이면 `"303"`과 `"330"`을 비교해 음수이므로 `"3"`이 앞이다. 비교를 뒤집으면 `"3033459"`처럼 가장 작은 수가 된다. 예제에서 바로 드러난다.
- `string.Concat`은 정렬하지 않는다. 정렬이 끝난 배열을 앞에서부터 붙인다. `["9", "5", "34", "3", "30"]`이면 `"9534330"`이다.
- `[0, 0, 0]`은 정렬해도 `"000"`이다. 맨 앞이 `"0"`이면 전부 `0`이므로 `"0"`을 반환한다. 만든 수를 `int`나 `long`으로 바꾸면 자릿수가 넘친다. 원소는 1000 이하, 길이는 10만 이하다.

## 문제 한 줄
`0` 이상 `1000` 이하인 수를 이어 붙여 만들 수 있는 가장 큰 수를 문자열로 반환한다.

## 핵심 패턴
```text
수를 문자열로 바꾼다
두 문자열 first, second에 대해
  (second + first)와 (first + second)를 비교해
  더 큰 결합이 되게 하는 쪽이 앞에 오도록 정렬한다
맨 앞이 "0"이면 "0"을 반환한다
아니면 정렬된 순서대로 붙인다
```

```csharp
string[] texts = new string[numbers.Length];

for (int index = 0; index < numbers.Length; index++)
    texts[index] = numbers[index].ToString();

Array.Sort(texts, (first, second) => (second + first).CompareTo(first + second));

if (texts[0] == "0")
    return "0";

return string.Concat(texts);
```

- `[6, 10, 2]` → `"6210"`. `"610" > "106"`, `"62" > "26"`, `"210" > "102"`
- `[3, 30, 34, 5, 9]` → `"9534330"`. 순서는 `9, 5, 34, 3, 30`
- `[0, 0, 0]` → `"0"`
- 시간은 `O(n log n)`이다. 비교마다 최대 8글자다. 문자열 배열 공간은 `O(n)`이다

## 대안별 구현 비교
세 방법 다 문자열로 붙인다. 순서를 정하는 비교만 다르다. 예제 둘과 `[0, 0, 0]`, `[10, 101]`, `[30, 301]`에서 갈라진다.

```csharp
string ByJoin(int[] numbers)
{
    string[] texts = new string[numbers.Length];

    for (int index = 0; index < numbers.Length; index++)
        texts[index] = numbers[index].ToString();

    Array.Sort(texts, (first, second) => (second + first).CompareTo(first + second));

    if (texts[0] == "0")
        return "0";

    return string.Concat(texts);
}

string ByNumberDescending(int[] numbers)
{
    int[] values = (int[])numbers.Clone();
    Array.Sort(values, (first, second) => second.CompareTo(first));

    string[] texts = new string[values.Length];

    for (int index = 0; index < values.Length; index++)
        texts[index] = values[index].ToString();

    if (texts[0] == "0")
        return "0";

    return string.Concat(texts);
}

string ByTextDescending(int[] numbers)
{
    string[] texts = new string[numbers.Length];

    for (int index = 0; index < numbers.Length; index++)
        texts[index] = numbers[index].ToString();

    Array.Sort(texts, (first, second) => second.CompareTo(first));

    if (texts[0] == "0")
        return "0";

    return string.Concat(texts);
}
```

- `ByJoin`이 제출용이다. 비교는 이어 붙인 두 문자열이다. 시간은 `O(n log n)`, 문자열 공간은 `O(n)`이다.
- `ByNumberDescending`은 수 하나의 내림차순이다. `[6, 10, 2]`가 `"1062"`다. 자릿수가 다르면 큰 수가 앞에 오는 것이 가장 큰 수를 만들지 않는다.
- `ByTextDescending`은 글자 내림차순이다. `[3, 30, 34, 5, 9]`가 `"9534303"`이다. `"30"`이 `"3"`보다 앞에 온다. `[10, 101]`은 글자 내림차순도 `"10110"`이라 이 쌍만 보면 맞다. `[30, 301]`은 `"30130"`이라 틀린다. `ByJoin`은 `"30301"`이다.
- 세 갈래 예외는 함수로 닫히지 않았다. `0`이면 뒤, 한 글자면 앞, 아니면 다음 자리가 큰 쪽으로 두면 `[3, 30, 34]`는 맞지만 `[3, 32]`와 `[30, 301]`에서 순서가 뒤집힌다.
